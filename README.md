# agnus-mobile

App mobile (Expo + React Native + TypeScript) da área do cliente do Agnus,
consumindo a API existente (`agnus-composer/agnus-back`) por HTTP.

> 🚧 Projeto em construção. O scaffold, a configuração de ferramentas e as telas
> são entregues em PRs por fase — ver `CHANGELOG.md` e os PRs do repositório.

## Fases

| Fase | Conteúdo |
| ---- | -------- |
| 0 | Setup: scaffold Expo, ESLint/Prettier/Husky/commitlint, `api/client.ts`, libs portadas, providers |
| 1 | Catálogo (sem login): Início, Catálogo, Produto |
| 2 | Autenticação: Login/Cadastro, SecureStore, guarda de rota |
| 3 | Carrinho + Checkout |
| 4 | Conta do cliente: dados, senha, endereços, contatos, pedidos |
| 5 | Polimento: estados de rede, pull-to-refresh, acessibilidade, ícone/splash |

## Rodando

Pré-requisitos e passos completos serão documentados na Fase 0.
